# DPOX180H Viewer

Программа для просмотра и анализа осциллограмм, сохранённых осциллографом **FNIRSI DPOX180H** в формате `.wav`.

![fmt: `DPOX180H Viewer.exe`](https://img.shields.io/badge/Windows-.exe-blue?style=flat-square)
![license: MIT](https://img.shields.io/badge/license-MIT-green?style=flat-square)

> Проект неофициальный и не связан с компанией FNIRSI.

## Что умеет

- открывает `.wav` через диалог выбора файла (или перетаскиванием в окно);
- показывает сводку: частота дискретизации, время/дел, В/дел, положение нуля, min/max, размах, среднее и СКЗ;
- создаёт CSV, PNG и **интерактивный HTML-график**;
- график рисуется непрерывной линией через каждый отсчёт — данные не теряются при зуме и прокрутке;
- в HTML доступны измерительные курсоры с расчётом `Δt`, `1/Δt` и `ΔU`.

## Требования

- Windows 7/10/11;
- .NET Framework 4.x и PowerShell 5.1 (уже входят в систему);
- современный браузер (Edge, Chrome) для интерактивного графика.

Установка не нужна: `exe` самодостаточен, рядом с ним не требуются дополнительные файлы.

## Быстрый старт

1. Запустите `DPOX180H Viewer.exe` двойным щелчком.
2. Нажмите **«Открыть .wav...»** и выберите файл осциллографа.
3. В окне появится сводка, в браузере откроется интерактивный график.

Можно запустить сразу с файлом:

```powershell
& "DPOX180H Viewer.exe" "1.wav"
```

## Создаваемые файлы

Рядом с выбранным `.wav` появляются:

| Файл | Содержание |
|---|---|
| `<имя>_decoded.csv` | время, напряжение и сырые значения ADC для всех отсчётов |
| `<имя>_view.png` | статический график в стиле экрана осциллографа |
| `<имя>_view.html` | интерактивный график (открывается в браузере) |

## Управление графиком

- колесо мыши — масштаб по времени;
- перетаскивание — прокрутка;
- двойной щелчок — сброс масштаба;
- наведение — время и напряжение в точке;
- клик — курсор **A**, Shift+клик или правый клик — курсор **B**;
- под графиком показываются `Δt`, `1/Δt` и `ΔU` между курсорами.

## Формат файла

`.wav` осциллографа DPOX180H **не является звуковым WAV**. Это собственный бинарный формат прибора: таблица секций, настройки, миниатюра экрана и массив 16-битных отсчётов ADC, все числа в big-endian.
